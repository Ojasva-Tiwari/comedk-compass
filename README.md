# COMEDK Compass

A COMEDK college and counselling guidance platform.

## Features

- Marks → Rank Predictor
- Rank → College Predictor
- College Database
- Budget Based College Search
- Preference List Builder
- Round-Wise Admission Chances
- Branch Upgrade Advisor
- College Comparison
- Counselling Alerts
- Prediction Confidence
- Student Data & Reviews
- Source Links for Data
- Historical Cutoffs
- Last Year Actual Cutoffs
- This Year Cutoff Estimates
- Seat & Vacant Seat Data
- Automatic COMEDK Data Updates
- College & Branch Search
- Cutoff Trend Analysis
- Prediction Testing
